# كاشير كبدة و سجق — Kebda & Sogo2 Cashier

Static site, no database. Orders are saved in the browser of the device that uses it.

## Deploy on Vercel
Option A — GitHub: push this folder to a new repo → vercel.com → Add New → Project → import the repo → Deploy (no settings needed).
Option B — CLI: inside this folder run `npx vercel --prod`.

## For the cashier
1. Use ONE device (tablet/laptop) and always the same browser. Don't use private/incognito mode.
2. Add it to the home screen (iPhone/iPad: Safari → Share → Add to Home Screen; Android: Chrome menu → Install app).
3. End of every day: سجل الطلبات → «نسخة احتياطية» and keep the file (send it to WhatsApp/Drive).
4. New device or data lost: open the site → سجل الطلبات → «استرجاع» → choose the backup file.
